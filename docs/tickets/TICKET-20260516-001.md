# AUTH Valid Login Succeeds

## Expected Outcome
A user can log in with the documented admin credentials and reach the authenticated application.

## Acceptance Criterion
- User can login with valid credentials: `admin@busana.com` / `admin123`.

## Public Test Interface
`e2e`, because this behavior must be proven through the public login page and authenticated redirect path.

## RED Expectation
The `AC-001-001` acceptance test fails when valid credentials do not authenticate or the UI does not reach an authenticated page.

## GREEN Expectation
The same `AC-001-001` acceptance test passes once valid credential login works through the UI.

## Smallest End-To-End Path
1. Visit `/login`.
2. Submit `admin@busana.com` and `admin123`.
3. Observe an authenticated page instead of the login page.
