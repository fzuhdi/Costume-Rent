## Expected Outcome
A successful login redirects the user to `/catalogue`.

## Acceptance Criterion

## Public Test Interface

## RED Expectation
The `AC-001-002` acceptance test fails when login succeeds but the browser does not land on `/catalogue`.

## GREEN Expectation

1. Visit `/login`.
2. Submit valid admin credentials.
3. Observe the browser URL ending in `/catalogue`.
