# AUTH Login Stores Token

## Expected Outcome
After login, the authentication token is stored in localStorage for session continuity.

## Acceptance Criterion
- Auth token is stored in localStorage after login.

## Public Test Interface
`e2e`, because token persistence must be proven from the browser after the public login flow completes.

## RED Expectation
The `AC-001-003` acceptance test fails when a successful login does not store a non-empty auth token in localStorage.

## GREEN Expectation
The same `AC-001-003` acceptance test passes once login persists the auth token in localStorage.

## Smallest End-To-End Path
1. Visit `/login`.
2. Submit valid admin credentials.
3. Inspect browser localStorage for a non-empty auth token.
