# Login Uses Theme-Aware Mobile Layout

## Acceptance Mapping
Criterion, expected outcome, test type, and spec files resolve from `.opencode/state/test-case-manifest.json` by `test_case_id`.

## RED Expectation
The `AUTH-014` Playwright acceptance test fails while the login page uses hardcoded light-only styling, loses contrast in dark mode, or has mobile usability issues for the existing credential flows.

## GREEN Expectation
The same `AUTH-014` acceptance test passes once the login page uses app theme tokens in light and dark mode, remains mobile usable, and preserves valid, invalid, and empty credential behavior.

2. Verify light and dark theme readability and mobile form usability.
3. Verify existing valid, invalid, and empty credential flows still behave correctly.
