# Client Detail And Form Are Mobile Usable

## Acceptance Mapping
Criterion, expected outcome, test type, and spec files resolve from `.opencode/state/test-case-manifest.json` by `test_case_id`.

## RED Expectation
The `CLIENT-015` Playwright acceptance test fails while mobile client detail or create/edit pages clip contact information, rental history, validation, edit/save actions, or destructive actions.

3. Open create or edit form and verify validation, cancel, and save actions remain usable.
