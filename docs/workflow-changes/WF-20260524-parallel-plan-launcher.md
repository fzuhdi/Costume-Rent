# WF-20260524-parallel-plan-launcher

## Status
implemented-reviewed

## Intent
Restore the intended default plan flow: execute tracer-bullet tickets in parallel by preparing up to three isolated ticket worktrees, each with its own Docker Compose runtime slot, Playwright base URL, runtime state, branch, and orchestrator task handoff.

## Scope
- Add `.opencode/scripts/launch-parallel-plan.mjs` as the deterministic parent prepare/handoff helper for plan targets.
- Keep ticket FSM execution inside each launched ticket worktree; do not merge ticket branches automatically in this slice.
- Make `/coordinator <plan-id>` route to the parallel prepare/handoff helper by default.
- Update workspace/runtime docs so max-3 parallel plan launch is the default plan model, not advanced/manual mode.
- Add dependency-aware batching so tickets with unmet `depends_on` prerequisites are excluded from parallel launch until prerequisites are complete.
- Copy allowlisted gitignored runtime env files into worktrees and preflight shared test dependencies/browser cache before runtime launch.
- Keep direct `/engineering/orchestrator <plan-id>` available for one-worktree/manual operation.
